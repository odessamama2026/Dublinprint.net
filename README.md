# DublinPrint — Custom Stickers

Static landing page, no build required. Serve the repository root.

React 18.3.1 production runtimes are hosted locally; app.js is precompiled. Styling, content and assets are preserved from the supplied design export. Google Fonts is an optional external font dependency.

Contact buttons scroll to the footer, which links to phone, email and Google Maps. No checkout or server-side form is included.
